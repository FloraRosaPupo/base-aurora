# Segurança

Não abra issues públicas com senhas, chaves ou dados pessoais. Para relatar uma vulnerabilidade, use o canal privado de segurança do repositório, quando disponível, ou o contato profissional da mantenedora.

O frontend público funciona sem credenciais. Configure chaves do modelo somente no backend. O limite de requisições do servidor é local ao processo e não substitui controle de consumo distribuído para um serviço público com chave paga. Consulte [ambiente](docs/ENVIRONMENT.md) antes de ativar geração externa.
