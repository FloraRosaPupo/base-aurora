# Como contribuir

Abra uma issue com o problema ou proposta. Faça um fork, crie uma branch e envie um PR com escopo claro, explicação da mudança e evidências de validação.

```sh
flutter test test/simulation_test.dart
node --test backend/test/*.test.mjs
flutter build web --release --output dist --no-wasm-dry-run
```

Mudanças de interface devem incluir uma captura e o navegador usado. Alterações científicas precisam indicar a fonte e distinguir princípios reais de regras didáticas. Nunca envie chaves, dados pessoais de alunos ou arquivos `.env`.
